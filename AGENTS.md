# GT3 project rules

Read README.md, HANDOFF.md, docs/gt3/PUBLICATION.md and decomp/gt3/schema.md first.
This repository is authoritative. Old experiments are preserved historical donors,
not alternate active projects. No new copied runtime checkouts.

- Selective recovery for explicit milestone needs, not full-game decompilation.
- Recover original behavior before modernization. Queue entries are not permission.
- Preserve upstream history/license/notices and newer reviewed runtime fixes.
- Original ISO/ELFs, generated bodies, protected executables, saves/cards, raw
  evidence and default launchers remain private and unchanged.
- No bulk add/reset/stash/clean, source-overwrite merges, assertion weakening,
  hash rewrites or force pushes to hide failures.
- New replacement needs bounded authorization, independent original oracle, exact
  differential/ABI/dynamic-cost tests, isolated default-OFF build AND runtime gates,
  profile guards/fallback, and enabled/disabled/trace-only live verification.
- Current main's recovered source library is not installed into the runtime.
  Historical frozen states do not establish equivalence of a newer integration.
- Preserve EE bit-pattern FP, integer wrapping/signedness, zero/invalid quirks and
  existing2e-6 tolerance. Use partial types, explicit padding and offset assertions.
- Interior label gates are not whole-function recovery; direct generated calls
  bypass dispatch. Keep downstream original physics unless separately authorized.
- Static findings, original-only fixtures, differentials, live observations and
  actual physical hardware proof are distinct. Keep neutral unknown/candidate names.
- Public site/schema/source tests require no proprietary artifacts. Explicit private
  verification must fail on missing/changed required artifacts; never silently skip.
- Do not publish raw assembly/decompiler dumps, original tables, generated game
  code, installed tooling, machine/session configuration, captures or credentials.
- Run just check, just test and just docs-build before a checkpoint claim. Record
  source/build context and unmet game-dependent gates honestly.
- No subsystem expansion, physical adapters/FFB or AI/reset/step implementation is
  authorized by consolidation. Stop at the user's requested checkpoint.
