title: Methodology and evidence levels
---

1. Choose a checkpoint necessity and smallest observable contract.
2. Preserve original identity and executable oracle; inspect retained evidence first.
3. Trace producers, mutations, units/representation and consumers, including fallback paths.
4. Establish partial layouts with honest unknowns and offset assertions.
5. Reconstruct readable behavior **without cleaning up original quirks**.
6. Differential-test original versus recovered code, including relevant bytes, EE arithmetic, ABI, returns and dynamic instruction cost.
7. Integrate behind build **and** runtime gates, default to generated, fallback safely outside evidenced scope.
8. Validate enabled, disabled and trace-only paths in the actual game. Freeze only the bounded contract proven.

## Evidence is not interchangeable

| Category | What it establishes | What it cannot establish alone |
|---|---|---|
| Static REA / assembly / pseudocode | Shipped instruction/data paths | Live object state, hardware calibration, real timing |
| Generated EE fixture | Executed original code in a controlled constructed state | Actual stock-car configuration, physical device behavior, arbitrary races |
| Differential fixture | Equivalence within tested state/domain | All possible modes, physical-PS2 numerical identity |
| Running native game | Actual integration with dynamic objects and downstream consumers | Every car/track, long-session reliability, audible/physical-display output unless measured |
| Hypothesis / naming inference | A prioritized investigation target | A recovered contract or authorized replacement |

The 22 pedal discovery fixtures are **original-only propagation checks**, not a clean/native differential and not live pedals. The steering live checks compare genuinely independent original and clean executions; clean semantic observers are bridge observations, not proof that skipped EE instructions ran.

REA pseudocode can have incomplete EE signatures, caller/return types and canonical containment. Requests at interior addresses may resolve to a different containing function. Use assembly/generated instructions before selecting boundaries; never turn requested selectors into asserted entry points automatically.

Retain failures and remediation. The initial pedal fixture aborted because a zero rev-limit configuration cut torque; the synthetic engine configuration was fixed, assertions were not relaxed. Record new evidence under a new artifact/ID rather than rewriting an old conclusion to hide a contradiction.
