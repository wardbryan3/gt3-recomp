## Deduplicated observations and selectors

- **One descriptor bit-pattern family**, present at both accelerator `0049D060`
  and brake `0049D070`; observed descriptor mode **1**. Exact fingerprint:
  `331b91ef5e1f42f3b4754157e0ea75cace5d14e1d40b02edc6b268bcd82d3b83`.
  No native-pad response call was observed: configured descriptor presence is
  **not descriptor execution**.
- **Five processing configurations**: command mode/effective-policy pairs
  **(2,0), (2,1), (3,0), (4,0), (4,1)**. All observed classification values were
  zero; blocking and auxiliary suppression were zero; representation-mask bits
  `0x0e` were set. The rate/floor fingerprint was constant across this matrix.
- The same-car AT/MT selections correlated with effective policies 0/1. This does
  not label other numeric policies. Policy selection uses original incoming kind,
  car+`14B8` blocking and car+`13E5` stored policy; their unvisited values remain
  outside this reachability claim.
- Native pad left-stick cases remained mode2; D-pad input reached mode3 (with its
  initial mode2 entry retained). **Modes2 and3 are not collapsed by the reducer.**
- Mode4 and **1,200 original response calls** came only from the two existing
  synthetic steering compatibility selections: 600 calls per descriptor address,
  derivative pointer null. They are **not native/physical wheel or analog-pedal
  reachability**. No new synthetic-pedal facility was introduced.
- Processing configuration identity is separate from admission. Original Time
  Trial, Free Run and B-1 used **`0049AF40`**; Single Race cases used **`0049AF50`**.
  Identical descriptor/policy fingerprints do **not** prove those pointer/alias
  contexts interchangeable. Only Time Trial was attempted against the clean gate;
  Free Run/B-1 remain original-only, not inferred clean failures or passes.
