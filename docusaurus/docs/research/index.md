Research preserves evaluated original findings, successful bounded recoveries,
stopped experiments, failed assumptions and unresolved questions. It is not an
alternate onboarding guide or an installation/approval ledger. Start with the
[Developer Guide](../developer-guide/index.md) to learn the method.

## How to interpret a report

Check the **evaluated base/overlay**, original profile, source hashes, observation
boundary, input population and actual execution mode. Synthetic, isolated,
full-CPU/full-RAM, wrapper, live substitution and hardware evidence are not
interchangeable. Failure/control runs remain failures. An unchanged historical
source hash is not a fingerprint of today's relocated file.

Later topic indexes qualify early interpretations without erasing the original
report. The [generated symbol inventory](../reference/generated/symbols.md) retains
candidate names; it is not the final interpretation of every address. Current
ownership/proof/approval semantics live in [Reference](../reference/authorities.md).
Use [current status](../start-here/current-status.md) and the single
[continuation checklist](../developer-guide/continuation.md), not historical “next” sections.
