---
title: Quick start — contribute without game files
---

The [Developer Guide](../developer-guide/index.md) is the primary learning path.
Use its [environment chapter](../developer-guide/environment.md) as the maintained
prerequisite checklist, then follow [public development](../developer-guide/build-and-run.md#public-development-no-game)
for clone, check, test and documentation commands. Those steps need no ISO, REA,
GPU SDK or private historical workspace.

A first successful public check means source consistency, not original-game
behavioral equivalence. Learn the [validation layers](../developer-guide/validation.md)
before interpreting a result.

Next, read the [repository map](../reference/repository-layout.md) and
[recovery method](../developer-guide/recovery-method.md). The
[worked MT selector](../developer-guide/worked-example-mt-selector/index.md)
connects those ideas to real source and tests without installing a recovery.

For ongoing work and handoffs, use only the
[current continuation checklist](../developer-guide/continuation.md). Historical
queues, stopped audits and handoffs are research context, not competing instructions.
